# Heizkörper-Check – Webseiten

Öffentliche Webseiten (Landingpage und kostenloser Schnellcheck) zum Projekt „Heizkörper-Check für Wärmepumpen“, veröffentlicht über GitHub Pages.

Die Dateien werden aus dem privaten Projekt-Repo übertragen (`tools/veroeffentlichen.ps1`). Änderungen bitte dort vornehmen, nicht hier.

Überschlag zur Orientierung. Ersetzt keine Heizlastberechnung nach DIN EN 12831 und keinen hydraulischen Abgleich. Nicht für Förderanträge geeignet.
